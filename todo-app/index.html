Containerized ToDo app

A REST API for to-do items, containerized with Docker and deployed to a server on AWS EC2.

Status: Built

DockerDocker ComposeFastAPIPostgreSQLAWS EC2

The problem

I wanted to learn containers by running something real: an API with a database, secrets kept out of git, and a deployment to a cloud server instead of only my laptop.

What it runs

A FastAPI backend, a PostgreSQL database and a frontend, started together with one Docker Compose file. The API image is built from my own Dockerfile, and the database uses the official PostgreSQL image.

How it is built

  • Dependencies are copied before the source code, so Docker can cache the dependency layer.
  • A named volume keeps the database data between restarts.
  • A health check makes the API wait until PostgreSQL is ready.
  • The containers reach each other by service name over Docker’s internal network.
  • Secrets live in a .env file that git ignores. The repo ships only an example file.

How it is deployed

The app runs on an Ubuntu 24.04 EC2 instance, with SSH limited to my IP address. A dedicated non-admin user runs the containers, so a compromised app does not get admin rights on the server.
